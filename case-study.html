A repository check
you can save and compare.

The Signal Desk checks three public GitHub repositories and compares their metadata with a saved snapshot. You add an interpretation before exporting a briefing with source links.

Try the research desk ↗

The problem

Research notes often mix observations, interpretations, and recommendations. Without a source and a prior snapshot, a change can sound more certain or more consequential than the evidence supports.

The approach

A fixed public watchlist covers Postiz, Ghost, and n8n. The desk reads public GitHub repository metadata and latest releases. It compares release tags, latest pushes, and license metadata with a prior snapshot, then asks for a human interpretation.

01 / Public sources→02 / Snapshot comparison→03 / Human review→04 / Source-attached brief

The demonstration

The first screen is a clearly labeled fictional fixture. Refresh replaces it only when all three public source checks succeed. A failed request keeps the prior snapshot intact. Imported JSON is marked unverified until refreshed; source reviews cannot be applied to fictional or imported data.

The result

The tool produces a Markdown brief and a JSON snapshot with sources, check times, observed changes, human notes, and draft/review states. It does not infer business results from stars, turn a push into a release, or claim a repository update improves ROI. Five core tests cover source restrictions, comparison, restoration, and export labeling.

Privacy and limits

No API token, private repository access, AI summary service, automatic publishing, background monitoring, or persistent storage is involved. Live refresh sends public requests to GitHub and depends on its availability and unauthenticated rate limits. Download your snapshot before reloading.
