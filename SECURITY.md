# Privacy and security boundary

Original source and fictional examples; no employer materials or private account data. The app requests only the three public watchlist repositories and their latest public releases from api.github.com, using credentials: omit. No token entry, backend, AI service, analytics, storage, or publication.

Human notes can be sensitive. Inspect them before sharing exports. Downloaded snapshots reopen as unverified drafts. Imported source links are reconstructed from an exact fixed allowlist; user text is rendered with textContent and Markdown escaping.

Live metadata is untrusted third-party source material. Review the canonical repository and license before making a decision. A push is not a release; stars are not sales or ROI. Report a reproducible defect through a GitHub issue without attaching private material.
